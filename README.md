# دفتر سالانه — ساخت APK با GitHub Actions

## بار اول
1. در GitHub یک مخزن **خصوصی (Private)** بساز، مثلاً `year-journal`.
2. همه‌ی فایل‌های این پوشه را آپلود کن (Add file ← Upload files). مهم است که پوشه‌ی `.github` هم برود
   (اگر از گوشی آپلود می‌کنی و پوشه‌ی مخفی دیده نمی‌شود، از کامپیوتر انجام بده).
3. به تب **Actions** برو. اگر ساخت خودکار شروع نشد، «Build APK» ← **Run workflow**.
4. بعد از حدود ۵ تا ۱۰ دقیقه، در بخش **Releases** مخزن فایل `year-journal.apk` هست. آن را دانلود و نصب کن
   (اندروید می‌پرسد «نصب از منبع ناشناس» را مجاز می‌کنی؟ موافقت کن).

## به‌روزرسانی برنامه
فایل `www/index.html` را با نسخه‌ی جدید برنامه عوض کن و Commit کن. ساخت خودکار شروع می‌شود.
APK جدید را روی نسخه‌ی قبلی نصب کن؛ **داده‌هایت می‌ماند**، چون هر بار با همان کلید (`journal.jks`) امضا می‌شود.

## نکته‌های مهم
- **فایل `journal.jks` را حذف یا عوض نکن.** با کلید دیگر، اندروید اجازه‌ی نصب روی نسخه‌ی قبلی را نمی‌دهد
  و باید برنامه را پاک کنی (و داده‌هایت هم می‌رود).
- مخزن را خصوصی نگه دار؛ کلید امضا داخل مخزن است.
- قبل از پاک کردن برنامه یا عوض کردن گوشی، از «تنظیمات ← پشتیبان‌گیری» فایل **JSON** بگیر.
- در برنامه‌ی اندروید، دکمه‌های خروجی (Excel و...) منوی اشتراک‌گذاری اندروید را باز می‌کنند؛
  از آنجا «ذخیره در فایل‌ها»، Drive، تلگرام یا باز کردن با Excel را انتخاب کن.
- گزینه‌ی چاپ/PDF در نسخه‌ی اندروید نیست.
